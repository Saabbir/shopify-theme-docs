The [Style Guides](/style-guides/) section tells you the rule. This section is different: it's for building actual understanding, step by step, of *why* the rule is the rule — worth reading when you have twenty minutes and want to go deeper than a quick reference.

## What's on this page group

- [CSS Deep Dive](/learning-articles/css-deep-dive/) — the cascade, specificity, and modern layout from first principles.
- [JavaScript & Web Components Deep Dive](/learning-articles/javascript-and-web-components-deep-dive/) — the custom element lifecycle and event model in depth.
- [Liquid Global Objects Reference](/learning-articles/liquid-global-objects/) — a thorough tour of the objects you'll use daily.
- [Managing Locale Files](/learning-articles/managing-locale-files/) — how to structure translations for multiple languages and countries without them rotting.
- [Writing Maintainable Code at Scale](/learning-articles/writing-maintainable-code-at-scale/) — what actually keeps a theme codebase manageable in year three, not just week one.

## How to use this section

These aren't reference pages you'll bookmark for daily lookups (that's [Reference](/reference/)) — they're written to be read start to finish, once, when you're building understanding of a topic rather than looking up a specific rule. New teammates: read these in roughly the order listed above during onboarding, alongside [Getting Started](/getting-started/).
